# ESP WCS — Wireless Console Server

Беспроводной консольный сервер на **ESP32-S3**. Плата подключается к консольному
порту коммутатора или маршрутизатора через MAX3232 и даёт доступ к его консоли
по Wi-Fi — из браузера, без кабелей до ноутбука и без интернета.

```
ноутбук ──Wi-Fi/HTTPS──▶ ESP32-S3 ──UART──▶ MAX3232 ──RS-232──▶ RJ45 консоль
                          (xterm.js)                              коммутатора
```

## Режимы

- **Direct connection** — ESP поднимает свою точку доступа, ноутбук подключается
  к ней, консоль открывается в веб-терминале (xterm.js по WebSocket).
- **Bastion connection** — ESP подключается к обычной Wi-Fi сети и сама держит
  mTLS-соединение с бастионом (свой сервер на Elixir/Phoenix). Все устройства
  и их консоли — в веб-интерфейсе бастиона.

Режим выбирается в веб-интерфейсе настройки, после чего настройка закрывается.
Вернуть её можно только физически — долгим нажатием кнопки на устройстве.

## Индикация

| Светодиод | Значение |
| --- | --- |
| ⚪ белый, ровно | заводское состояние, не настроено |
| 🔵 синий, дышит / ровно | настройка: ждёт подключения / клиент подключён |
| 🟢 зелёный, тускло / дышит / ровно | Direct: точка доступа выключена / ждёт подключения / клиент подключён |
| 🟣 фиолетовый, дышит / ровно | Bastion: подключается / онлайн |
| 🟡 жёлтый, дышит | Bastion: ждёт одобрения на бастионе |
| 🔴 красный, дышит | нет связи с бастионом |
| 🔴 красный, часто мигает | ошибка прошивки |
| вспышки | идут данные консоли |

Кнопка BOOT: удержание 5 с — «Настройка» (при удержании мигает синим),
15 с — сброс до заводских (мигает красным). Действие — при отпускании.
Подробно — [`docs/led.md`](docs/led.md).

## Железо

- ESP32-S3-DevKitC-1 v1.1, модуль ESP32-S3-WROOM-1-N16R8 (16 МБ Flash, 8 МБ Octal PSRAM)
- модуль MAX3232 (питание строго 3.3 В) и кабель RJ45, распиновка Cisco
- консоль: UART1, GPIO17 (TX) / GPIO18 (RX)

Справочник по плате и распиновка — [`docs/hardware/esp32-s3-n16r8-board.md`](docs/hardware/esp32-s3-n16r8-board.md).

```
firmware/     прошивка ESP32-S3 (ESP-IDF v6.1)
  main/       точка входа, board.h — все пины здесь
  components/ модули прошивки (wcs_*)
bastion/      сервер-бастион на Elixir/Phoenix (этап 2)
docs/         ТЗ, план работ, установка, справочник по железу
```

## Сборка

Нужен ESP-IDF v6.1 ([`docs/setup.md`](docs/setup.md)).

```sh
cd firmware
idf.py set-target esp32s3   # один раз
idf.py build
idf.py -p /dev/ttyACM0 flash monitor
```

## Быстрый запуск (Makefile)

Из корня репозитория, `make` без аргументов — список команд:

```sh
make setup      # бастион: БД, зависимости, администратор из bastion/.env (один раз)
make run        # бастион: https://localhost:4443, устройства — порт 7443
make device     # тестовое устройство WCS Link, ARGS="--id … --name …"
make fw-build   # прошивка (после get_idf)
make fw-flash   # PORT=/dev/ttyACM0
```
