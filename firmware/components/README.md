# Компоненты прошивки

Каждый модуль прошивки — отдельный компонент ESP-IDF в своей папке
(`components/wcs_<имя>/`) с публичным заголовком в `include/` и явными
зависимостями в `REQUIRES` / `PRIV_REQUIRES`. `main` только собирает их вместе.

Компоненты этапа 1 (по ТЗ, раздел «Модули прошивки»):

| Компонент | Назначение | Статус |
| --- | --- | --- |
| `wcs_defaults` | заводские настройки, генерируются из `firmware/.env` | есть |
| `wcs_button` | кнопка: подавление дребезга, события «клик», 5 с, 15 с | есть |
| `wcs_wifi` | точка доступа WPA2/WPA3, клиент Wi-Fi с переподключением, поиск сетей | есть (без таймера выключения) |
| `wcs_auth` | PBKDF2-хэш пароля, сессии, защита от перебора | есть (пароль пока только заводской) |
| `wcs_web` | веб-сервер: вход; в «Настройке» — мастер выбора режима, в Direct — консоль. Маршруты — таблицы `web_route_t` с уровнем доступа (вход проверяется в одном месте). Файлы из `www/pages/` и `www/assets/` встраиваются генератором `gen_www.py`, крупные тексты сжимаются gzip | есть, HTTPS |
| `wcs_storage` | настройки в NVS: режим, Wi-Fi для бастиона, адрес бастиона | есть |
| `wcs_tls` | ключ ECDSA P-256 и самоподписанный сертификат HTTPS: создаются при первом запуске, хранятся в NVS (`wcs_tls`), сброс до заводских их не стирает | есть |
| `wcs_bastion` | адрес бастиона (порт по умолчанию 7443), проверка доступности: DNS / mDNS `.local` + TCP | есть, без протокола |
| `wcs_console` | UART консоли, мост WebSocket ↔ UART, BREAK | — |
| `wcs_fsm` | машина состояний: «Заводское», «Настройка», Direct, Bastion | пока в `main/main.c` |
| `wcs_led` | RGB-светодиод: цвет, характер свечения, слои (`docs/led.md`) | есть |

Связь между компонентами — через публичные API и события `esp_event`
(например, `WCS_BUTTON_EVENT`). Настраиваемые параметры компонента — в его `Kconfig`
(`idf.py menuconfig` → «ESP WCS: …»).

Как добавить в веб-интерфейс:

- **страницу** — файл в `wcs_web/www/pages/` и маршрут с `.access = WEB_ACCESS_PAGE`,
  обработчик — `web_send_file(req, "pages/<имя>.html")`;
- **скрипт, стиль, картинку** — файл в `wcs_web/www/assets/`, доступен по `/assets/<имя>`
  сам, CMake править не нужно (незнакомый тип файла — добавить в `TYPES` в `gen_www.py`);
- **API** — маршрут в таблице режима (`web_setup.c` / `web_direct.c`). Поле `.access`
  можно не указывать: по умолчанию нужен вход. `WEB_ACCESS_PUBLIC` — только осознанно.

Правила:

- пины и параметры железа берутся только из `main/board.h` (передаются в компоненты через конфигурацию при инициализации);
- компонентам, использующим PSRAM, — `esp_psram` в `PRIV_REQUIRES`;
- драйверы указывать явно (`esp_driver_uart`, `esp_driver_gpio`, …).
