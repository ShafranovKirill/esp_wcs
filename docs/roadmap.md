## Этап 1 (MVP) — Direct connection

Сделано вне порядка ТЗ (ветка `feat/setup-portal`): удержание BOOT 5 с поднимает
точку доступа настройки, вход администратора (PBKDF2, сессии, защита от перебора),
выбор режима Direct / Bastion (поиск Wi-Fi, проверка подключения, адрес бастиона),
хранение режима в NVS, машина состояний, индикация, сброс до заводских по 15 с.
Заводские пароли — из `firmware/.env`.

Ветка `feat/direct-console`: компонент `wcs_console` (UART, параметры линии, BREAK,
история в PSRAM), xterm.js во флеше, мост WebSocket ↔ UART по HTTPS, «Устройство занято»,
свои SSID и пароль Direct в мастере настройки. Осталось проверить на железе (пункт 1).

Не делаем: смену пароля администратора через веб-интерфейс — пароли задаются
в `firmware/.env` до сборки, в прошивку попадает только хэш.

1. [ ] Связка ESP → MAX3232 → консоль коммутатора: эхо UART через USB-порт ESP
2. [ ] Точка доступа, веб-сервер, xterm.js, мост WebSocket ↔ UART — сделано сразу по HTTPS, ждёт проверки на плате
3. [x] HTTPS с генерацией сертификата на устройстве (ECDSA P-256, хранится при сбросе до заводских; HTTP → HTTPS перенаправление)
4. [ ] Вход, сессии, хэши паролей, защита от перебора, «Устройство занято»
5. [ ] Веб-интерфейс настройки, хранение настроек в NVS
6. [ ] Машина состояний, кнопка, светодиод, закрытие настройки после выбора режима
7. [ ] Таймер выключения точки доступа, ограничение на одного клиента
