# Индикация RGB-светодиода

Встроенный WS2812 на GPIO48 (`BOARD_RGB_LED_GPIO` в `firmware/main/board.h`),
яркость ~40 из 255 (`BOARD_RGB_LED_BRIGHTNESS`).

## Принципы

- **Цвет — режим.** Белый — заводское, синий — настройка, зелёный — Direct,
  фиолетовый — Bastion, жёлтый — ожидание одобрения на бастионе.
- **Характер свечения — что происходит внутри режима.**
- **Красный — только проблемы.**

## Характер свечения

| Свечение | Значение | Параметры |
| --- | --- | --- |
| ровно | режим работает, всё спокойно | |
| ровно, тускло | режим работает, но ничего не происходит | ~1/3 яркости |
| дышит | ждёт: подключения, настройки, ответа | плавно, период 2 с |
| часто мигает | внимание: подтверждение действия или ошибка | 5 Гц |
| вспышки | идут данные консоли | короткое погасание ~30 мс на порцию данных, не чаще 10 раз в секунду |

## Состояния

| Состояние | Цвет | Свечение | Когда |
| --- | --- | --- | --- |
| Загрузка | ⚪ белый | одна вспышка | первые ~0.5 с после включения |
| **Заводское** (не настроено) | ⚪ белый | ровно | |
| **Настройка**, точка доступа поднята | 🔵 синий | дышит | после удержания кнопки 5 с, ждёт подключения |
| Настройка, клиент подключился | 🔵 синий | ровно | |
| **Direct**, точка доступа выключена | 🟢 зелёный | ровно, тускло | ждёт короткого нажатия кнопки |
| Direct, точка доступа поднята | 🟢 зелёный | дышит | ждёт подключения (таймаут 5 минут) |
| Direct, клиент подключился | 🟢 зелёный | ровно | |
| Direct, открыт терминал | 🟢 зелёный | ровно + вспышки на данных | |
| **Bastion**, подключение | 🟣 фиолетовый | дышит | Wi-Fi или бастион ещё не на связи |
| Bastion, ждёт одобрения | 🟡 жёлтый | дышит | заявка висит на бастионе |
| Bastion, онлайн | 🟣 фиолетовый | ровно + вспышки на данных | |
| Bastion, нет связи с бастионом | 🔴 красный | дышит | требование ТЗ |
| Ошибка прошивки | 🔴 красный | часто мигает | сбой инициализации, не поднялся Wi-Fi |

## Подсказки при удержании кнопки

Действие выполняется при **отпускании** кнопки. Пока она удерживается,
светодиод подсказывает, что произойдёт:

| Удержание | Индикация | Если отпустить |
| --- | --- | --- |
| < 5 с | без изменений | короткое нажатие (в Direct — поднять точку доступа) |
| 5–15 с | 🔵 синий, часто мигает | вход в «Настройку» |
| ≥ 15 с | 🔴 красный, часто мигает | сброс до заводских настроек |

## Слои

Итоговое свечение собирается из слоёв, верхний перекрывает нижние:

1. **Подсказка кнопки** — пока кнопка удерживается дольше 5 с.
2. **Активность консоли** — вспышки поверх базового свечения.
3. **Базовое свечение** — по текущему состоянию устройства.

Когда верхний слой снимается, автоматически возвращается нижний.

## Реализация

- Компонент `wcs_led` (компонент `espressif/led_strip`, RMT) знает только цвета
  и характер свечения, анимацию ведёт в своей задаче. О состояниях устройства он не знает.
- Соответствие «состояние → цвет и свечение» — одна таблица в машине состояний
  (`wcs_fsm`, пока `main`). Поменять цвет — одна строка.
- Кнопка (`wcs_button`) публикует события «достигнуто 5 с» и «достигнуто 15 с»
  во время удержания — по ним включается подсказка.
- Планируется настройка «гасить светодиод в рабочем режиме» (для стойки ночью);
  подсказки кнопки и красные состояния при этом всё равно показываются.
