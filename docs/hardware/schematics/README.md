# Схемы ESP WCS

Основной комплект чертежей для документации и дипломной работы.

| Обозначение | Наименование | Векторный оригинал | Изображение |

| WCS.02 | Схема электрическая принципиальная | [SVG](wcs-schematic.svg) | [PNG](wcs-schematic.png) |

## Оформление

- Формат A3, альбомная ориентация, белый фон, чёрные линии и текст.
- Рамка, основная надпись, обозначение документа и номер листа.
- Позиционные обозначения элементов, номера контактов и имена электрических цепей.
- Схемы отражают проектное исполнение устройства, включая внешнюю кнопку S1.
- Временные статусы реализации, результаты испытаний, предупреждения и инструкции
  по сборке размещаются в текстовой документации, а не на чертежах.
- При изменении соединений синхронно обновляются обе схемы, SVG и PNG.

Для вставки в диплом и масштабирования используется SVG; PNG предназначен
для просмотра и редакторов без поддержки SVG.

Описание подключения и результаты проверки — [console-wiring.md](../console-wiring.md).
